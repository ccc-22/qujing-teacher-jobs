# 曲靖教师编制雷达

帮曲靖的老师自动追踪"有编制"的教师招聘机会。每天早上 8:30 自动抓取，双击 `打开网站.bat` 查看。

## 怎么用

| 想做什么 | 怎么做 |
|---|---|
| 看最新机会 | 双击 `打开网站.bat`（或直接双击 `index.html`） |
| 手动刷新一次 | 双击 `刷新数据并打开网站.bat` |
| 自动刷新 | 已配置 Windows 计划任务 `QujingTeacherJobs_DailyFetch`，每天 08:30 自动运行（电池模式也会跑；错过时间开机后会自动补跑） |

## 数据从哪来

- 曲靖市人社局（事业单位 / 公示公告栏目）
- 云南省人社厅（招考招聘栏目）
- 华图教育云南站（教师招聘 / 特岗公告）
- 山香教育（云南事业单位汇总 + 教师招聘公告）

## 过滤规则

1. **收录**：标题含 招聘/引进/特岗/选调/招募，且涉及教师、教育、学校或事业单位
2. **排除**：编外、合同制、劳务派遣、临聘、代课、公益性岗位、编制外、民办、第三方
3. **排除**：成绩公示、资格复审、体检考察、拟聘名单等流程类公告
4. **排除**：考什么科目、什么时候报名等资讯问答类文章
5. **排除**：报名已截止的公告、发布超过 60 天的老公告
6. **编制标注**：正文含"事业编制/纳入编制/公开招聘/人才引进"等标 ✓；仅有模糊信息的标 ⚠ 请点原文核实

## 覆盖地区

曲靖全市（麒麟/沾益/马龙/陆良/师宗/罗平/富源/会泽/宣威）置顶；
周边（昆明、昭通、贵州兴义/黔西南/六盘水/盘州）单独归类；云南其他州市也有收录，可用地区筛选查看。

## 文件说明

- `fetch.py` —— 抓取脚本（每天计划任务自动运行，也可手动运行）
- `template.html` —— 网站模板（改样式改这里）
- `index.html` —— 生成的网站（每次抓取后自动重建，双击即开）
- `data.json` —— 结构化数据（以后迁移到 GitHub Pages 就用它）
- `store.json` —— 本地数据库（已分析过的公告缓存，避免重复抓）
- `probe*.py` / `check.py` —— 开发调试用的探测/检查脚本，可删
